# GitHub Achievements Playground

Git Badges Playground is an interactive GitHub achievements sandbox for developers who want to learn by doing.

Instead of only reading a list of GitHub profile achievements, users can fork this repository and run scripts that create real GitHub workflow events in their own repository.

## Why This Exists

Many GitHub achievements require normal platform activity:

- Opening pull requests
- Merging pull requests
- Closing issues quickly
- Co-authoring commits
- Helping in Discussions
- Building repositories people want to star

This project turns the mechanical parts into a guided practice flow while still encouraging responsible, real activity.

## Main Script Modes

```bash
bash scripts/unlock.sh status
bash scripts/unlock.sh pull-yolo
bash scripts/unlock.sh pair
bash scripts/unlock.sh quickdraw
```

Windows PowerShell:

```powershell
.\scripts\unlock.ps1 -Mode status
.\scripts\unlock.ps1 -Mode pull-yolo
.\scripts\unlock.ps1 -Mode pair
.\scripts\unlock.ps1 -Mode quickdraw
```
