# Galaxy Brain Guide

Galaxy Brain is earned through accepted answers in GitHub Discussions. This one should not be automated, because the point is to help people with real questions.

## How To Approach It

Find public repositories that have Discussions enabled and where you understand the topic.

Look for questions that are:

- Unanswered
- Recent
- Specific enough to solve
- Related to tools or languages you know

Write answers that include:

- The likely cause
- A clear fix
- A short explanation
- A code snippet or command when useful
- A link to official docs when appropriate

## Good Answer Pattern

```text
The issue is probably caused by <cause>.

Try this:

<command or code>

Why this works:
<short explanation>

If it still fails, check <specific thing>.
```

Only the discussion author or maintainers can mark an answer as accepted. Do not pressure people to accept your answer.
